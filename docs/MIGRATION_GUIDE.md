# Пошаговое руководство по миграции и синхронизации
*Проект: legal_estate | Среда: Antigravity | Стандарт: аналогично estate_agency_bot*

Привет! Это простое и понятное руководство по переносу и синхронизации проекта **legal_estate** между твоими компьютерами (например, домашним ПК и рабочим ноутбуком).

Мы построили `legal_estate` ровно по тому же принципу, что и `estate_agency_bot`: проект живёт в директории `D:\Антигравити\legal_estate`, подключен к Git/GitHub и зарегистрирован в панели «Проекты» Antigravity. 🚀

---

## 🌟 Способ 1. Синхронизация через GitHub (Рекомендуемый, как в estate_agency_bot)

Это самый удобный способ: ты работаешь на одном компьютере, нажимаешь `git_push.bat`, приходишь на второй компьютер, нажимаешь `git_pull.bat` — и все документы, сделки и наработки мгновенно обновлены!

### Шаг 1. Создание репозитория на GitHub (разово, на первом ПК)
1. Зайди в свой профиль GitHub: [github.com/Rucyno](https://github.com/Rucyno).
2. Нажми зеленую кнопку **«New»** (Создать новый репозиторий).
3. В поле *Repository name* укажи: `legal_estate`.
4. Выбери **Private** (Частный) или Public на своё усмотрение.
5. ⚠️ **Важно**: галочки *«Add a README file»* и *«Add .gitignore»* **НЕ ставь** (они у нас уже созданы в проекте).
6. Нажми **«Create repository»**.
7. В папке `D:\Антигравити\legal_estate` просто дважды кликни на файл:
   ```text
   git_setup.bat
   ```
   Скрипт автоматически отправит весь проект на GitHub! При необходимости подтверди вход в окне авторизации браузера.

---

### Шаг 2. Развертывание на втором компьютере / ноутбуке
1. Установи **Antigravity** и **Python 3.12** (обязательно с галочкой *"Add python.exe to PATH"*).
2. Установи библиотеку для работы с документами Word (в PowerShell):
   ```bash
   pip install -r requirements.txt
   ```
   *(или просто `pip install python-docx openpyxl`)*.
3. Открой консоль (PowerShell или Git Bash) в твоей папке с проектами Antigravity (например, `D:\Антигравити\`):
   ```bash
   cd D:\Антигравити
   git clone https://github.com/Rucyno/legal_estate.git
   ```
4. Открой **Antigravity**:
   - Нажми **File ➡️ Open Folder...** (или `Ctrl + O`).
   - Выбери папку `D:\Антигравити\legal_estate`.
   - Проект мгновенно появится в левой панели **«Проекты» (Projects)** рядом с `estate_agency_bot`! ✨

---

### Шаг 3. Ежедневная синхронизация между устройствами (в 1 клик)
- **Закончил работу на компьютере 1**: дважды кликни на `git_push.bat` (все новые договоры, расписки и изменения улетят на GitHub).
- **Сел за компьютер 2**: дважды кликни на `git_pull.bat` (все файлы скачаются за 2 секунды).

## 💾 Способ 2. Перенос через флешку или архив (Офлайн)

Если нет интернета или не хочется подключать GitHub:

1. **Скопируй со старого компьютера**:
   - Папку проекта: `D:\Антигравити\legal_estate` *(или готовый ZIP-архив `LegalEstate_Migration_Pack.zip` с Рабочего стола)*.
   - Папку конфигурации Antigravity: `C:\Users\PC\.gemini\config`.
2. **Вставь на новом компьютере**:
   - Папку проекта в `D:\Антигравити\legal_estate` (или по пути проектов на новом ПК).
   - Папку `config` в `C:\Users\<Твое_Имя>\.gemini\config`.
3. **Открой в Antigravity**:
   - В приложении Antigravity нажми **File ➡️ Open Folder...** и выбери папку `legal_estate`.
   - Проект автоматически добавится в область «Проекты»!
