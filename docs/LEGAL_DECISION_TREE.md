# Дерево правовых решений и Полный Регламент Агента-Юриста (Legal Decision Tree)
*Источник: Реальная практическая технология проведения сделок «Этажи» (г. Пенза)*  
*Утверждено по итогам глубинного интервью: 2026-11-09*

## 1. Сквозной Чек-лист преддоговорного аудита сделки (Шаг за шагом)

Перед составлением ПДКП или ОДКП юрист последовательно прогоняет сделку по 5 контрольным фильтрам:

```
┌────────────────────────────────────────────────────────────────────────┐
│ 1. ПРАВОУСТАНОВКА (Документы-основания в выписке ЕГРН)                  │
│ ├─ ДДУ / Цессия ──> Требуем справку застройщика о 100% оплате + МСК     │
│ ├─ Приватизация ──> Архивное дело БТИ (ордер, домовая, отказы)          │
│ ├─ Наследство   ──> Заверения ст. 431.2 ГК РФ от неучтенных наследников │
│ └─ ДКП          ──> Проверка исполнения расчетов по прошлой сделке      │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ 2. СОБСТВЕННИКИ И ПОЛНОМОЧИЯ (Субъекты, Браки, Дети, Доверенности)     │
│ ├─ Брак + возмездное ──> Нотариальное согласие / Брачник / Раздел       │
│ ├─ Использован МСК   ──> Двухэтапный ПДКП: сначала выдел долей детям    │
│ │                        по соглашению, затем ПДКП для Опеки -> Нотариус│
│ └─ По доверенности   ──> Чек-лист: открытие счетов во ВСЕХ банках,      │
│                          снятие залога, основной расчет СТРОГО на счет  │
│                          собственника (поверенному только задаток/комса)│
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ 3. ОБРЕМЕНЕНИЯ И ДОЛГИ (Ипотека продавца, Приставы ФССП)               │
│ ├─ Ипотека продавца:                                                   │
│ │   ├─ ПВ покупателя >= долга ──> Гашение через СБР/аккредитив          │
│ │   ├─ Банк без СБР           ──> Внесение на ипотечный счет + дельта   │
│ │   └─ ПВ покупателя < долга  ──> Решение: переодобрение в банк продавца│
│ │                                 (запрет МСК на чужой залог!)          │
│ └─ Запрет приставов (ФССП):                                            │
│     ├─ Расчет: сумма долга по базе ФССП + 10% (пени/сбор)               │
│     ├─ Задаток строго <= 100 000 руб., всё свыше = аванс/часть цены     │
│     └─ Срок: снятие до 30 дней, покупатель платит сам по квитанции РОСП │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ 4. ЦЕНА, НЕДОФИНАНСИРОВАНИЕ И ФОРМА РАСЧЕТОВ                           │
│ ├─ Полная цена        ──> Стандартный расчет (наличные / СБР / кредит)  │
│ ├─ Недофинанс (нал)   ──> ПДКП на полную цену; в день ОДКП: ДКП на 2 млн│
│ │                         + ДС на дельту с маркировкой экземпляров      │
│ │                         + 2 расписки + штраф 50к за утечку            │
│ └─ Недофинанс (ипот.) ──> Если ПВ > цены ДКП: формулировка «часть цены  │
│                           без точной цифры» + кредит на «неотделимые    │
│                           улучшения» (соответствие отчету об оценке)    │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ 5. ПРОПИСКА И ПЕРЕДАЧА КЛЮЧЕЙ (Передаточный акт)                       │
│ ├─ Прописка: строго ДО сделки по адресной справке МВД (базово 95%)     │
│ ├─ Передача (Наличные): ДО сделки прямо на объекте + счетчики + Акт    │
│ ├─ Передача (Безнал/СБР): в течение 3 дней ПОСЛЕ зачисления денег      │
│ └─ Альтернатива (цепочка): выписка и ключи до 21–30 дней после оплаты   │
│ └─ Спасательный круг: «Риск третьей стороны» (отказ банка/опеки/ФССП   │
│    = возврат задатка как аванса в 1-кратном размере без штрафов)       │
└────────────────────────────────────────────────────────────────────────┘
```

## 2. Матрица трансформации: Как ответы превращаются в пункты договора

| Ситуация на сделке (Триггер) | Как реагирует Агент-Юрист | Точный пункт в ПДКП / ОДКП |
|---|---|---|
| **Долг приставам 300 000 руб.** | Дробит сумму на задаток и аванс. Покупатель платит сам. Срок до 30 дней. | **п. 2.2**: «Сумма 100 000 руб. передается в качестве задатка, а сумма 200 000 руб. — в качестве обеспечительного платежа в счет оплаты Объекта и направляется Покупателем на закрытие ИП №... в Первомайском РОСП г. Пензы». **п. 4.2**: «При срыве сделки Продавец возвращает двойной задаток 200 000 руб., а обеспечительный платеж 200 000 руб. подлежит возврату в течение 3 дней». |
| **Ипотека Сбера 2 млн, у покупателя ПВ 800 тыс.** | Блокирует ручное гашение. Переводит покупателя в Сбербанк. | **п. 1.2**: «Сделка осуществляется с использованием целевых кредитных средств ПАО Сбербанк по технологии расчетов с одновременным погашением задолженности Продавца по кредитному договору №... и перечислением остатка Продавцу». |
| **Был использован МСК, доли детям не выделены** | Блокирует выход на ОДКП. Включает двухэтапный регламент. | **В ПДКП-1**: «Продавцы обязуются в срок до «___» заключить соглашение об определении долей, наделить несовершеннолетних долями и предоставить согласованный проект ДКП в орган опеки. Срок ОДКП устанавливается не позднее 14 дней с момента получения приказа опеки». |
| **Сделка с доверенностью** | Проверяет полномочия. Выводит деньги на счет собственника. | **п. 2.3**: «Денежные средства за вычетом суммы задатка и согласованного вознаграждения перечисляются в безналичном порядке исключительно на банковский счет законного Собственника №... в ПАО...» |
| **Недофинанс (цена 3.5 млн, в ДКП 2 млн)** | Готовит комплект защиты от ФНС. Маркирует экземпляры. | **п. 2.1 ПДКП**: «Цена Объекта составляет 3 500 000 руб. Стороны договорились в Основном ДКП указать 2 000 000 руб., а разницу в размере 1 500 000 руб. зафиксировать Дополнительным соглашением с условиями конфиденциальности». |
| **Отказ банка по ипотеке или опеки** | Включает «Риск третьей стороны». Спасает задаток. | **п. 4.4 ПДКП**: «В случае невозможности заключения ОДКП вследствие обстоятельств, не зависящих от воли Сторон (отказ Банка в согласовании Объекта/заемщика, отказ органа опеки в выдаче приказа), сумма задатка признается авансом и возвращается Покупателю в течение 3 рабочих дней без применения штрафных санкций». |
| **Наличный расчет за объект** | Назначает осмотр и Акт ДО сделки. | **п. 3.1 ОДКП**: «Передача Объекта, ключей и подписание Передаточного акта с контрольной фиксацией показаний приборов учета производятся Сторонами непосредственно на Объекте до подписания настоящего Договора и подачи документов на регистрацию». |
| **Расчет через СБР / Аккредитив** | Откладывает ключи до зачисления денег. | **п. 3.1 ОДКП**: «Фактическая передача Объекта, ключей и подписание Передаточного акта производятся Сторонами в срок не позднее 3 (трех) рабочих дней с момента фактического зачисления денежных средств со счета СБР/аккредитива на счет Продавца». |
