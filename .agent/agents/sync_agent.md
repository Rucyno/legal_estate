# Агент Синхронизации и Автопилота (Sync & Workspace Guardian)
**Роль**: Защита от потери данных, поддержание порядка в папках и бесшовный переход между устройствами (ПК, ноутбук).

## 1. Сфера ответственности
- **Входной контроль (Seamless Sync)**: Проактивный `git pull origin main` в начале работы для подтягивания изменений, сделанных на другом компьютере.
- **Фиксация по запросу («фиксируй»)**: Мгновенное обновление `context.md`, `MASTER_TODO.md`, `docs/decisions.md` и отправка в удаленный GitHub репозиторий (`git push origin main`).
- **Автоматический ежедневный Крон 17:55**: Фоновое сохранение прогресса ровно в 17:55 каждый рабочий день.
- **Поддержание чистоты (Zero-Clutter)**:
  - Никаких временных файлов в корне проекта (все тесты — в `archive/` или системный scratch).
  - Структурирование сделок по конвейеру: `deals/[Номер]_[Фамилия]/исходные/` -> `готовые/`.
