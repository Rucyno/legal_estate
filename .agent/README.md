# Архитектура Независимых Агентов LegalEstate
*Обновлено: 2026-10-30*

Этот проект переведён на **систему 5 независимых модульных агентов**. Каждый агент имеет изолированную зону ответственности, собственные инструменты и нормативную базу.

## Карта агентов

| Агент | Файл профиля | Специализация | Нормативная база и Инструменты |
|---|---|---|---|
| 🔍 **Inspector Agent** | `.agent/agents/inspector_agent.md` | **Инспектор сделки**: прием первичных файлов (фото паспортов, ЕГРН), валидация адресов (ФИАС), выявление затыков до начала составления договора. | `deals/*/исходники/`, парсинг реквизитов, сверка сумм расчетов |
| ⚖️ **Legal Agent** | `.agent/agents/legal_agent.md` | **Правовой эксперт**: составление ДКП, ПДКП, ДС, передаточных актов, расписок. 13 отраслей права, указание на ошибки со статьями законов. | `docs/LEGAL_KNOWLEDGE_BASE.md`, дайджест Росреестра, `templates/` |
| 📐 **Layout Agent** | `.agent/agents/layout_agent.md` | **Дизайн и верстка (Legal Design)**: Правило 10 (подписанты во всю ширину), 1 страница А4, счетчики с отступами, сравнение версий, перевод на юридический язык. | `python-docx`, Word COM, стандарты типографики |
| 🛡️ **Security Agent** | `.agent/agents/security_agent.md` | **Офицер безопасности**: фоновая проверка людей по государственным реестрам (ФНС, ФССП, Федресурс, суды), реестр `MASTER_LOG.xlsx`. | Модуль проверок, скриншоты, официальные шлюзы РФ |
| 🔄 **Sync Agent** | `.agent/agents/sync_agent.md` | **Синхронизация и порядок**: бесшовный переход между ПК и ноутбуком (git pull при входе, push в 17:55 и по команде «фиксируй»). | Git, системный scheduler, крон-задачи |

## Главный протокол работы (Zero Overhead Policy)
1. **Инспектор** проверяет исходники и находит нестыковки.
2. **Юрист** собирает правовую конструкцию со статьями кодексов и законов.
3. **Верстальщик** упаковывает документ в чистый Word строго на нужный объем страниц без визуальных дефектов.
4. **Синхронизатор** автоматически бэкапит результат в облачный хаб.
