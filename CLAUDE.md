# LegalEstate — Юридический Центр Сделок с Недвижимостью
*Конфигурация проекта для Claude Code*

## О проекте
Система автоматизированной подготовки, правовой экспертизы и корректировки пакетов юридических документов для сделок с недвижимостью (предварительные и основные договоры купли-продажи, соглашения о конфиденциальности, расписки, соглашения о расторжении, займы, претензии застройщикам).
Обеспечивает перенос данных из выписок ЕГРН и ПДКП в ОДКП, актуализацию дат, расчеты через аккредитив, СБР, маткапитал СФР, долевую собственность и антифрод-защиту (ст. 178, 179, 431.2 ГК РФ, 255-ФЗ).

Статус: **✅ Работает (Активная база сделок)**.

---

## 🛠️ Стек технологий
- **Язык:** Python 3.12+
- **Обработка документов:** `python-docx` с прямой манипуляцией XML (`parse_xml`, `w:pBdr`, `w:tabs`, таблицы, подписи)
- **ИИ и OCR:** `gpt-4o-mini` для распознавания сканов и фото паспортов РФ
- **Генерация QR-кодов:** `qrcode`, `pillow` (ГОСТ Р 56042-2014 для госпошлин Росреестра)
- **Библиотека эталонов:** 17 шаблонов «Этажи Стандарт» в папке `templates/`

## 🚀 Основные команды

### Создание новой сделки:
```bash
# Интерактивное создание сделки с распознаванием паспорта
python scripts/new_deal.py --passport path/to/passport.jpg

# Генерация QR-кода на оплату госпошлины Росреестра
python scripts/generate_state_duty_qr.py --amount 2000
```

### Визуальный контроль и аудит верстки:
```bash
python scripts/visual_inspector.py
```

## 📐 Структура проекта
- `deals/` — Папки конкретных сделок с исходными данными и готовыми документами (`01_...` до `15_...`).
- `templates/` — Официальные эталонные шаблоны договоров (ДКП, ПДКП, Займы, СОПД, Акты).
- `scripts/` — Утилиты генерации, аудита верстки, генерации QR госпошлин.
- `docs/` — Матрица расчетов (`deal_matrix.md`), деревья условий, регламенты.
- `MASTER_LOG.xlsx` — Сводный реестр проверок и сделок.
- `context.md` — Единый источник правды о статусе сделок.

## 🔒 Юридические и стилистические правила (Zero-Tolerant QA)
1. **Шрифты и верстка:** Только `Times New Roman` (10pt или 12pt в зависимости от шаблона). Запрещен дефолтный сброс в `Calibri`.
2. **Абзацы и интервалы:** Строго одинарный межстрочный интервал (1.0) и абзацный отступ 1.25 см.
3. **Антифрод-оговорки:** Во всех договорах обязательно включать защитные оговорки по ст. 431.2 ГК РФ, заверения об обстоятельствах и статус иноагентов (255-ФЗ).
4. **Контроль долей и сумм:** Суммы в договоре прописью должны до копейки совпадать с цифрами и суммами расписок.
