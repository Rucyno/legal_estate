# legal_estate — Юридический Центр Сделок с Недвижимостью
*Автоматизированная подготовка, правовая экспертиза и оформление сделок в Antigravity*

Добро пожаловать в проект **legal_estate**! 🌸 Проект размещён в рабочей директории проектов Antigravity (`D:\Антигравити\legal_estate`) и настроен по единому корпоративному стандарту с `estate_agency_bot`.

## 🚀 Синхронизация и миграция между устройствами

Подробная инструкция находится в [docs/MIGRATION_GUIDE.md](docs/MIGRATION_GUIDE.md).

- **На основном ПК**: создай пустой репозиторий `legal_estate` на GitHub и запусти `git_setup.bat`.
- **На новом ПК / ноутбуке**: склонируй репозиторий в `D:\Антигравити\legal_estate` и открой папку в Antigravity. Проект автоматически появится в списке проектов!
- Для ежедневной работы используй `git_push.bat` (отправить) и `git_pull.bat` (получить).

## ⚖️ Правовой контур и безопасность
Все документы в проекте разработаны в строгом соответствии с законодательством РФ:
- **ГК РФ**: ст. 160, 421, 434 (электронная форма и свобода договора), ст. 380–381 (задаток), ст. 244 (долевая собственность);
- **152-ФЗ**: защита персональных данных сторон сделки (Zero-Trace Policy);
- **255-ФЗ**: гарантии об отсутствии статуса иностранного агента;
- **127-ФЗ**: защита сделок от рисков оспаривания по закону о банкротстве.
